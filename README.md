# Test Task

Тестовый проект на вакансию HTML верстальщика, собранный на React.js/SCSS с использованием методологии БЭМ. Адаптивный под мобильные устройства, поддерживает все современные браузеры.

## Запуск проекта

```bash
cd test-task-app
npm install
npm start
```

Проект откроется в браузере по адресу `http://localhost:3000`

## Сборка проекта

```bash
npm run build
```
